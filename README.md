## Overview

Bondeth Content Studio is a planned video production framework for creating educational programming videos with code instead of a timeline editor. Using [Remotion](https://www.remotion.dev/), every scene, animation, and code walkthrough is a React component. That makes videos versionable, reusable, and easy to update when the content changes.

> **Status: in planning.** Implementation has not started yet. This README describes the intended direction.

## Planned Features

- **Scenes as React components,** composed into full lessons.
- **Animated code walkthroughs** with syntax highlighting and step-by-step reveals.
- **Reusable templates** for intros, outros, titles, and lower thirds.
- **Consistent branding** through shared themes and design tokens.
- **Programmatic rendering** to MP4 with Remotion.
