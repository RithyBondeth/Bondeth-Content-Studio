# Music beds

Background music for the explainer videos. Pick one in the editor's Music
setting, or let the script step choose one by mood (see `src/lib/music.ts`).
The music fades in and out and ducks under the narration
(`src/lib/ducking.ts`).

None of these files were downloaded. Each one is synthesized from scratch by
[`pipeline/music.ts`](../../pipeline/music.ts) using sine tones, additive
harmonics and seeded, filtered noise, with no samples or third-party
recordings. Run `npm run music` to regenerate them; the output is identical
on every run.

Every bed is a whole number of bars, and notes that ring past the end wrap
around to the start, so each file loops seamlessly.

| File          | Mood    | Feel                                                       | Length  | Source                           | Licence |
| ------------- | ------- | ---------------------------------------------------------- | ------- | -------------------------------- | ------- |
| `calm.wav`    | Calm    | Slow warm pads and soft bells, C major, 64 BPM             | 30.00 s | Generated by `pipeline/music.ts` | CC0 1.0 |
| `upbeat.wav`  | Upbeat  | Plucked arpeggios, bass and a light beat, D major, 120 BPM | 32.00 s | Generated by `pipeline/music.ts` | CC0 1.0 |
| `curious.wav` | Curious | A syncopated mallet figure over pads, A minor, 90 BPM      | 32.00 s | Generated by `pipeline/music.ts` | CC0 1.0 |

All three files are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/): you
can copy, modify and use them, including commercially, without asking or
crediting anyone.

Format: mono, 16-bit PCM WAV at 22.05 kHz, all scaled to the same RMS level
(about -18 LUFS) so they sound equally loud at the same volume. Playback
volume is set per video in the spec (`music.volume`, 0.15 by default), not in
the files.

Tracks you upload in the editor are not stored here: they go in the video's
media folder under `public/content/`, next to its voice-overs.
