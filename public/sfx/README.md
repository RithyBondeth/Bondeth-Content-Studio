# Sound effects

Short sounds played under the explainer videos (see `src/lib/sfx.ts`).

None of these files were downloaded. Each one is synthesized from scratch by
[`pipeline/sfx.ts`](../../pipeline/sfx.ts) using sine tones and seeded,
filtered noise, with no samples or third-party recordings. Run `npm run sfx`
to regenerate them; the output is identical on every run.

| File         | Used for                                            | Length | Source                         | Licence |
| ------------ | --------------------------------------------------- | ------ | ------------------------------ | ------- |
| `whoosh.wav` | Slide and wipe transitions                          | 0.50 s | Generated by `pipeline/sfx.ts` | CC0 1.0 |
| `rise.wav`   | Zoom transitions                                    | 0.60 s | Generated by `pipeline/sfx.ts` | CC0 1.0 |
| `pop.wav`    | A list item, comparison side or code step appearing | 0.14 s | Generated by `pipeline/sfx.ts` | CC0 1.0 |
| `tick.wav`   | A stat's count-up starting                          | 0.06 s | Generated by `pipeline/sfx.ts` | CC0 1.0 |

All four files are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/): you
can copy, modify and use them, including commercially, without asking or
crediting anyone.

Format: mono, 16-bit PCM WAV at 44.1 kHz, peaking at about -3 dBFS. Playback
volume is set in `src/lib/sfx.ts`, not in the files.
